# よく使うライブラリ

## 適用対象

全プロジェクト共通。

## 規約

以下のライブラリをよく使う。バージョンは固定しない。

- `zustand` — グローバルなstate管理
- `swr` — データフェッチ・キャッシュ
- `motion` — アニメーション
- `tailwind` — スタイリング
- `clsx` — クラス名の条件分岐・結合
- `dnd-kit` — ドラッグ&ドロップ
- `lucide-react` — アイコン
- `tailwind-merge` — Tailwindのクラス名競合を解決
- `react-hook-form` — フォーム
- `oxlint` — リンター
- `oxfmt` — フォーマッタ
